# 二叉树基础知识

## 二叉树种类

- **完全二叉树**
    - **定义**：一个二叉树中，除了最后一层外，每一层的节点数都达到最大值，且最后一层的节点都连续集中在最左边。
    - **特点**：
        - 节点数最多的二叉树。
        - 叶子节点只能出现在最下层和次下层。
        - 示例图片：
            ![完全二叉树示例](https://camo.githubusercontent.com/266eac058b52c6e595263d276bb58a87ac763c1b075c1fe82742d75078ff341b/68747470733a2f2f696d672d626c6f672e6373646e696d672e636e2f32303230303932303232313633383930332e706e67)
- **满二叉树**
    - **定义**：一个二叉树中，每一层的节点数都达到最大值。
    - **特点**：
        - 所有叶子节点都在同一层。
        - 每个节点都有两个子节点，除了叶子节点。
        - 示例图片：![满二叉树示例](https://camo.githubusercontent.com/97964c2f92c843fe6a19cb30c9e1f06533e92d6b512ee67c39970470095c9948/68747470733a2f2f696d672d626c6f672e6373646e696d672e636e2f32303230303830363138353830353537362e706e67)
- **二叉搜索树**
    - **定义**：一个二叉树中，任意节点的左子树中的所有节点的值都小于该节点的值，右子树中的所有节点的值都大于该节点的值。
    - **特点**：
        - 中序遍历结果是一个递增的有序序列。
        - 查找、插入和删除操作的时间复杂度为 O(log n)。
        - 示例图片：![满二叉树示例](https://camo.githubusercontent.com/35e4fe336d2a05be1b1f904289c05dfb630e7ae9ff69cf7e388743ca72489614/68747470733a2f2f696d672d626c6f672e6373646e696d672e636e2f32303230303830363139303330343639332e706e67)
- **平衡二叉树**
    - **定义**：一种二叉搜索树，其中每个节点包含额外的平衡信息（通常是高度或平衡因子），以确保树的高度保持在对数级别。
    - **特点**：
        - 任意节点的左右子树高度差不超过1。
        - 动态操作（插入、删除）后需要进行旋转操作以保持平衡。
        - 示例图片：![满二叉树示例](https://camo.githubusercontent.com/274f601aebd82fca3553444dba9b7d3e942cbc46449429ddc808ee183aa84eed/68747470733a2f2f696d672d626c6f672e6373646e696d672e636e2f32303230303830363139303531313936372e706e67)
